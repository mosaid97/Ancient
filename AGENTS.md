## 1. Project Overview

**Name:** Ancient China Knowledge Graph  
**Purpose:** A knowledge graph system for Ancient China history — ingesting, processing, and querying historical data using LLMs, OCR, and a Neo4j graph database.  
**Stack:** Python (uv), Neo4j, OpenAI-compatible LLM API (Silra), Docker Compose

## 2. Environment & Configuration

- All secrets live in `.env` — **never hard-code credentials**.

```

NEO4J_URI            — bolt://localhost:7687 (or bolt://neo4j:7687 inside Docker)
NEO4J_USERNAME       — neo4j (Neo4j Docker image rejects any other initial admin name)
```

- Always load env with `python-dotenv`: `from dotenv import load_dotenv; load_dotenv()`
- Use `os.getenv("KEY")` — never `os.environ["KEY"]` directly (prefer safe fallback).

## 3. Python Conventions

- **Runtime:** Python 3.12, managed via `uv`.
- **Run code:** `uv run python <file.py>` — never activate the venv manually.
- **Add deps:** `uv add <package>` — never `pip install`.
- **Formatting:** Follow PEP 8. Prefer explicit over clever.
- **Type hints:** Required on all function signatures.
- **Docstrings:** Google-style for public functions and classes.
- **Error handling:** Always catch specific exceptions; log with context before re-raising.

---

## 4. Neo4j Graph Conventions

- Use the official `neo4j` Python driver (`neo4j>=6.2.0`).
- All Cypher queries must be parameterized — **no string interpolation in queries**.
- Node labels use `UPPER_SNAKE_CASE` (e.g., `PERSON`, `DYNASTY`, `EVENT`, `DICTIONARY_ENTRY`). Single-word labels are simply uppercase (`TOPIC`, `DOCUMENT`).
- Relationship types use `UPPER_SNAKE_CASE` (e.g., `RULED_BY`, `PRECEDED_BY`).
- Property keys use `camelCase` (e.g., `startYear`, `chineseName`).
- Always close driver sessions; prefer `with` blocks.

```python
# ✅ GOOD
with driver.session() as session:
 result = session.run("MATCH (d:DYNASTY {name: $name}) RETURN d", name=dynasty_name)
```

## 5. LLM / Silra API Conventions

- Use the `openai` SDK pointed at `LLM_BASE_URL` (OpenAI-compatible endpoint).
- Model routing:
  - OCR tasks → `OCR_LLM_MODEL` (`deepseek-ocr`)
  - Embedding tasks → `EMBED_LLM_MODEL` (`text-embedding-v4`)
  - Chat/reasoning tasks → `CHAT_LLM_MODEL` (`deepseek-chat`)
- Always include a system prompt that anchors the model to Ancient China domain context.
- Retry on transient failures with exponential backoff (max 3 retries).
- Log token usage when available.

## 6. Docker & Infrastructure

- Local dev: `docker compose up -d` starts Neo4j + app.
- Neo4j browser available at `http://localhost:7474`.
- App service waits for Neo4j health check before starting.
- Volumes: `neo4j_data`, `neo4j_logs`, `neo4j_import` — never delete without backup.
- For schema changes: write a migration script, not a manual Cypher session.
